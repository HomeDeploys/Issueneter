# docs/plans

Состояние контролируемого пайплайна разработки для фич этого проекта.

- `.active` — slug фичи, над которой сейчас идёт работа (per-project,
  мутируется по ходу процесса).
- `<slug>/plan.md`, `<slug>/progress.md` — план и прогресс конкретной
  фичи, живут до её мерджа, потом удаляются `close-feature`.

Полный формат, статусы, шаблоны и то, как всё это обновляется —
см. `PLAN_FORMAT.md` рядом с skill `dev-pipeline` (устанавливается
глобально, не копируется в этот репозиторий — см. README кита).
